# B747 Jumbo Experience

実寸大のボーイング747-400を観察・搭乗できるXRift教育系ワールド。

![thumbnail](public/thumbnail.png)

## 特徴

- **実寸大の747-400**（全長70.6m／全幅64.4m／全高19.4m）をプロシージャルジオメトリで再現
  - アッパーデッキのこぶ、後退角37.5度の主翼、4発エンジン、16輪の主脚、反り上がったテールコーンなど
- **搭乗体験**: GATE 47の階段→搭乗橋（ボーディングブリッジ）→L2ドアから機内へ
  - メインデッキ（ファースト＋エコノミー約500席）、階段で2階アッパーデッキ（ビジネス）、最前部のコックピットまで歩いて回れる
- **パーツ解説**: 機体の16箇所（レドーム・スラット・フラップ・エルロン・スポイラー・ウィングレット・エンジン・パイロン・尾翼・降着装置・APUなど）をクリックすると、観察デッキの解説ボードに日本語の説明を表示。選択はインスタンス内で共有
- **機体分解モード**: 観察キオスクのボタンで機体全体が分解（主翼・尾翼・エンジン・降着装置・レドーム・APUが分離して浮遊し、ラベル表示。レドームの中の気象レーダーも見える）
- **ターボファンエンジン分解展示**: 地上の実寸大CF6級エンジン模型を8モジュール（ファン〜排気ノズル）に分解して各部の役割を学べる
- **観察キオスク**: 機内・2階・コックピット・尾翼ビュー・翼端ビューへのテレポートボタン付き

## 状態同期（useInstanceState）

| キー | 内容 |
|------|------|
| `b747-selected-part` | 選択中のパーツID（解説ボードに表示） |
| `b747-exploded` | 機体分解モード |
| `b747-engine-exploded` | エンジン展示の分解状態 |

## スケール

機体・搭乗ゲート・寸法マーカーは**1.25倍の展示スケール**（`WORLD_SCALE`）で表示しています（通路や細部をゆったり鑑賞できるように）。プラカードの数値は実機の実寸を表記。キオスク・解説ボード・エンジン展示は等身大です。コライダーはreact-three-rapierがworld scaleを焼き込むためスケールグループ内でそのまま動作します。テレポート先はワールド座標（スケール後）で指定しています。

## モデリングメモ

- 胴体はLatheGeometry（96分割×放射80分割）で実寸プロファイル生成。**尾部は2段テーパー**（z-14.5〜-24は緩やかに半径3.25→2.6、以降テールコーン）＋頂点シアーの反り上げで、客室（後方隔壁 z=-24）を船体内に完全に収納
- **こぶ（アッパーデッキ）はスーパー楕円断面のロフト**（[humpProfile.ts](src/components/B747/humpProfile.ts) の制御点から72断面×30点を生成）。コックピット斜面→フラットな頂部→ティアドロップ後方フェアリングが一体で繋がる。コックピット風防帯も同じプロファイルに追従するコンフォーマル帯
- 機内も尾部に合わせて後方は2-4-2席に絞り、テーパー付き内壁シェル・斜めコライダーで包含（参考: JAL/Boeing カットアウェイ図）
- 塗装（白＋グレー腹部＋紺チートライン）は**頂点カラー**で胴体全長に直接ペイント。曲面に完全追従する
- ドーサルフィン・主翼・尾翼はShape+ExtrudeGeometry。**鋭角頂点にbevelを付けるとマイター爆発で巨大ポリゴンが発生する**ためフィンはbevel無効
- 航法灯（左赤・右緑）、衝突防止灯（点滅ビーコン上下）、ギアドア、駐機中にゆっくり回るファン付き
- 内装は実機写真準拠: ヘッドレスト＋IFE画面付き座席（インスタンシング6セット）、室内窓グロー、クラス仕切り、744型6画面グラスコックピット（PFD/ND×2＋EICAS縦2）・オーバーヘッドパネル・ベージュ内装

## 日本語フォント

drei `<Text>` のデフォルトフォントはCJK非対応で、troikaのCDNフォールバックはXRiftの権限サンドボックス下で不安定なため、**Noto Sans JPのサブセット（public/NotoSansJP-Subset.woff, 約90KB）を同梱**し、全テキストを [JPText](src/components/JPText.tsx) 経由で描画しています。

**表示テキストを変更したらサブセットを再生成すること**（含まれない文字は描画されません）:

```bash
curl -sL -o NotoSansJP-var.ttf "https://github.com/google/fonts/raw/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf"
pip install fonttools
python subset-font.py   # src内の使用文字を自動収集してwoffを再生成
```

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck
npm run build
npm run check      # xrift check world --build（アップロード前の事前検査）
```

### スクリーンショット用ヘルパー

dev起動中にリポジトリルートから実行（カメラ位置はURLパラメータで指定）:

```bash
TARGET_URL="http://localhost:5173/?cam=40,10,53&look=0,9.5,0" node worlds/b747-experience/screenshot.mjs out.png
# サムネイル（dev UIを隠してcanvasのみ撮影）
TARGET_URL="http://localhost:5173/?cam=40,10,53&look=0,9.5,0" node worlds/b747-experience/thumbnail-shot.mjs public/thumbnail.png
```

dev専用URLパラメータ: `?cam=x,y,z`（カメラ位置）/ `?look=x,y,z`（注視点）/ `?exploded=1`（機体分解）/ `?engine=1`（エンジン分解）

`?cam=`指定時はレンダリングを乗っ取ってカメラを毎フレーム固定します（devのプレイヤーは物理で落下するため、`useFrame(cb, 1)`＋手動`gl.render`でピン留め。座標はスケール後のワールド座標で指定）。
