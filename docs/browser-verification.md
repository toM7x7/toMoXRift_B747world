# ブラウザ検証記録（2026-09-05）

- `npm run typecheck`: 合格。
- `npm run build`: 合格。
- `node scripts/verify-exhibition-floors.mjs`: GLB実形状の40点床確認に合格。
- 実ブラウザで横並び3作品、Sol原作全景、Astra原作全景、Astra飛行シーンを描画し、`docs/screenshots`に記録。
- ブラウザ内で登録された実Interactableコールバックを呼び、全景切替、飛行移動と帰還、両作品の上階移動と帰還を実行。開発プレイヤーの物理座標で着地を確認。

## 元アセットとの差異

Solの元GLBはすべて灰色だった。元Blender内に記録されたRGBAを使用して書き出し色を補正し、形状とアニメーションのBINチャンクが不変であることを確認。Astraの複雑なガラス材質はglTF互換材質へ近似。詳しくは各取り込み記録を参照。
- 飛行再生ボタン実行後、実ノード`FLIGHT_AIRCRAFT_ROOT001`の位置が1.8秒間で(85,50,-3)から(53.731,55.004,1.360)へ変化。飛行アニメーションの再生を確認。
